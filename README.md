An entry for the make.fun competition
[The Word You'd Delete From the Dictionary](https://make.fun/c/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2).

The entry word is:

> **pneumonoultramicroscopicsilicovolcanoconiosis**

The longest word in the English language — 45 letters, a lung disease caused
by inhaling fine silica dust, and a word nobody can say, spell, or use
without taking a deep breath first. Erasing it frees the dictionary of its
own punchline: a word so long it barely counts as a word. The joke is the
word itself.

## Run

```sh
node main.ts
```

Writes the single entry word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`).
